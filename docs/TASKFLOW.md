# 任务审核

## MiniMax 接入

右上角打开 **MiniMax 接入**，填写完整的 HTTPS Chat Completions 地址（以 `/chat/completions` 结尾）和自己的 API Key。当前支持公司图像模型 `HORIZON-MiniMax`，不自动回退到其他模型。

公司内网接口需要公司网络或 VPN。若出现 TLS 握手失败或连接超时，先确认 VPN 已连接、公司网关可访问，再重试；这类连接失败不代表 API Key 无效。

保存后显示“待首次调用验证”；任务请求成功后显示已连接。保存本身不发起推理。分析会将采样画面及所选反馈摘要发送到配置的接口，消耗该 API 的额度。

密钥存放在 `workspace/taskflow/minimax-local.json`，采用原子写入，文件权限为 `0600`。页面不回显密钥，不使用浏览器存储保存密钥。同一接口留空密钥可保留原值；更换接口地址必须重新填写。

**断开接入** 清除个人接入文件中的密钥并禁用调用，不会回退到旧凭据。有排队或运行中的任务时，需等待任务结束才能更改接入。

## 建立范本

在数据工作台打开 **任务范本**：

1. 在弹窗的 **导入数据** 页签选择采集记录，点击 **加入审核数据**；也可上传参考视频。
2. 回到 **任务范本** 页签，在 **范本录像** 中选择该素材。
3. 可填写任务要求，明确期望的结束状态。
4. 点击 **解析范本**，模型生成任务目标、阶段类别和可观察的完成条件。
5. 在 **查看与编辑完成条件** 中核对并保存修改。

模型生成的定义是提案。保存会更新范本版本；目前没有独立的审批或启用状态。旧结果保留使用时的范本版本。

## 审核另一条数据

打开记录，选择任务范本、分析方式和检查范围，点击 **开始自动审核**。

- **画面＋机器人反馈**：使用有效的身体关节、手部状态和角速度反馈组织证据。
- **纯视觉**：使用采样画面判断。
- **整段／指定时间区间**：只统计所选范围；边界前后的画面可能用于核对结果。

首次使用 MCAP 的机器人反馈时，系统自动解析原始关节与手部数据，无需预先打开记录。解析失败会停止分析并显示原因。

待审录像独立切段，不沿用范本的时间比例。阶段可重复、回退、跳过；后一次成功不覆盖前一次失败。

页面显示当前步骤和已用时。任务中断或失败后，可恢复原配置重试；点击开始才会重新提交。取消会等待当前模型请求结束，不会撤销已经发生的 API 用量。

## 查看与复核

录像、3D 姿态和关节反馈共用播放器及时间轴。点击阶段、证据画面或反馈曲线可定位到对应时刻。

右侧包含：

- **完成条件**：每项条件的模型判断、原因和画面证据。
- **模型输入**：从请求存档读取实际发送的画面与反馈摘要。
- **人工复核**：记录修订及说明，与模型原始结果分别保存。

**已完成** 表示模型认为条件均有证据支持；**未完成** 表示存在失败或放弃的结果证据；**证据不足** 表示结果不可见、条件缺失或动作尚未结束。只分析局部区间的结果不代表整条任务结论。

分段边界可以修订。修改边界后，相关判断需重新复核。审核 JSON 包含范本版本、时间区间、模型来源、人工修订和证据索引。

## 数据与限制

MCAP 适配 G1 的 29 个身体关节、左右手各 6 维及相机通道。反馈以 20 Hz 因果对齐，超过 150 ms 的陈旧值视为无效。用于模型的是采样与派生摘要，并非全部原始关节数组。

身体关节和手指运动用于定位动作时机，不能证明接触、抓住或物体入篮。腕部轨迹相对骨盆，不是世界坐标；IMU 角速度不表示平移。模型无法从遮挡或单目图像中推断精确距离、受力或碰撞安全。

视频上传支持 MP4、MOV、MKV、WebM、AVI、M4V，需要 FFmpeg 和 ffprobe。单文件上限 1 GB，时长 0.2 秒至 60 分钟。长录像和快速动作可能因采样遗漏，应结合原始回放核对。

接口失败不会生成模拟预测。相同模型、说明和图像可复用本机响应缓存，结果中保留缓存来源。模型预测尚不能代替独立人工真值评测。

## 文件配置兼容

没有个人接入文件时，服务可读取 `ROBOCURATE_VLM_CONFIG` 指定的文件，或 `workspace/taskflow/company-vlm.json`。模型必须为 `HORIZON-MiniMax`。凭据可通过 `api_key_file` 或 `api_key_env` 提供。

个人接入配置优先；断开后保留禁用标记。旧配置及外部凭据文件不被删除。所有实际凭据、请求存档和原始数据均不得加入源码包。
