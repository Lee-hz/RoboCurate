# 任务审核

## 接入 MiniMax

打开右上角 **MiniMax 接入**，填写 HTTPS Chat Completions 地址（以 `/chat/completions` 结尾）和自己的 API Key，模型为 **HORIZON-MiniMax**。公司内网接口需先连接公司网络或 VPN。

保存后显示「待首次调用验证」，首次任务请求成功后显示已连接。分析会向网关发送采样画面及所选反馈摘要，使用个人 API 额度。

同一接口留空密钥可保留原值；更换地址需重新填写。任务结束后可修改配置或断开接入。密钥保存方式见[安全说明](../SECURITY.md)。

## 建立范本

在数据工作台打开 **任务范本**：

1. 在 **导入数据** 中选择采集记录，点击 **加入审核数据**，或上传视频。
2. 回到 **任务范本**，选择 **范本录像**，按需填写任务要求。
3. 点击 **解析范本**，生成任务目标、阶段和完成条件。
4. 在 **查看与编辑完成条件** 中核对并保存。

保存修改会更新范本版本，已有审核结果保留原版本。

## 审核数据

打开另一条记录，选择范本、分析方式和检查范围，点击 **开始自动审核**。

| 设置 | 输入与范围 |
| --- | --- |
| 画面＋机器人反馈 | 采样画面及身体关节、手部、角速度摘要；首次使用时自动解析 MCAP |
| 纯视觉 | 采样画面 |
| 整段／指定区间 | 判断所选范围，边界附近画面用于补充上下文 |

待审录像独立划分阶段，支持重复尝试、回退和跳过。每次尝试分别保留结果。

页面显示当前步骤和已用时。失败后可恢复配置重试；取消任务需等待当前模型请求结束，已发生的用量仍计入 API 额度。

## 核对结果

录像、3D 姿态和关节反馈共用时间轴。点击阶段、证据画面或反馈曲线可定位回放。

- **完成条件**：模型判断、原因和证据。
- **模型输入**：实际发送的画面与反馈摘要。
- **人工复核**：修订判断并保存，与模型结果分别保留。

| 模型判断 | 含义 |
| --- | --- |
| 已完成 | 各项完成条件均有证据支持 |
| 未完成 | 有失败或放弃的结果证据 |
| 证据不足 | 结果不可见、条件缺失或动作尚未结束 |

修订分段边界后需重新复核判断。导出的 JSON 包含范本版本、审核区间、模型来源、人工修订和证据索引。

## 数据格式

- **G1 MCAP**：相机、29 个身体关节、左右手各 6 维及 IMU 角速度。反馈按 20 Hz 对齐，超过 150 ms 的陈旧值标为无效。模型接收采样与派生摘要；完整时序可在本机查看。
- **坐标**：腕部轨迹相对骨盆；IMU 显示角速度。抓取和放置结果需结合画面核对。
- **视频**：MP4、MOV、MKV、WebM、AVI、M4V；单文件最大 1 GB，时长 0.2 秒至 60 分钟，需要 FFmpeg 和 ffprobe。
