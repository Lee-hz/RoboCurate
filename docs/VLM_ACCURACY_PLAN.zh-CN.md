# 人形移动操作审核：准确率改进与训练路线

2026-10-14。本文是基于项目现状及论文原文整理的方案；文中新增的信号融合、训练和评测流程尚未实施。

## 当前要解决的具体错误

MiniMax 在当前搬运记录中，将第一次“放入与松手释放”判为完成，随后又在“释放后留置”阶段发现物体在筐外，并推断曾入篮后掉出。现有图像不能支持这一完整因果过程。这暴露出三个问题：遮挡下的空间关系判断、跨阶段的结果观察，以及把看不清的过程补成一个故事。

训练数据必须区分两件事：物体实际在哪里，以及所提供的画面是否足以判断。即使仿真状态给出了真值，如果给模型的画面被遮挡，也不能一律要求它输出确定答案；应为可观测性单独标注。

项目的范本审核目前使用公司推理接口。人工复核会保存记录，但不会自动更新 MiniMax 或 OG 的权重。公司是否开放这些模型的微调、训练权限及权重，需要另行确认；现有 API 密钥本身不等于具备训练能力。

## 建议的实施顺序

### 1. 先建立人工验收集

标注对象是每一次独立尝试及其阶段，不能用“整条最后成功”覆盖中间失败。每条标注至少包括：任务和阶段目标、开始和结束时间、尝试编号、完成/未完成/证据不足、对应画面，以及简短的可见事实。

覆盖正常完成、空抓、抓后滑落、放在容器旁、释放后才看清落点、失败后重抓、手撤回但整体未离开等情况。标注者应能查阅原始多路画面和可用传感器记录；争议片段应保留争议，不由模型自身裁决。

现有 VLM 输出只作为预标注。已经反复用于调试的 episode_000009 应属于开发回归集，不能继续充当独立测试集。训练、验证和测试按整条采集记录划分，条件允许时进一步按采集批次、操作者和场景分组；相邻帧不可跨集合。当前数据规模和多样性不足以宣称泛化准确率。

### 2. 先改输入证据，再决定是否微调

借鉴 ProTracer：根据机器人状态变化提出候选边界，选择有信息量的帧，再把简短的状态摘要与画面一同送给 VLM。阶段语义仍由任务范本和视频决定，候选边界不等于最终阶段，也不限制阶段顺序或重复次数。

对 G1 的适配要点：

- 对齐相机、身体关节和手部信号的时间戳，核实哪些是反馈、哪些是控制指令。
- BrainCo 多指手不能直接套用论文中单一夹爪开度。先定义张开、闭合、维持姿态的可解释特征；手收拢不能直接证明握住了物体。
- 利用关节和机器人结构计算末端相对机身的运动。人形机器人整体移动时，相对机身静止不代表相对桌面静止；需要区分身体运动与手臂运动。IMU 姿态也不能直接替代平移定位。
- 优先补充能看清手、物体和目标容器的腕部或头部画面，而非反复发送相同信息。
- 放置后保持观察，直到结果可见、出现新的操作，或录像结束。若缺少必要证据，保留证据不足；不能仅凭透过筐壁看到红色轮廓就确认入篮，也不能由后来物体在桌面倒推它一定先入篮再掉出。

这些变化不要求重训公司大模型。应先比较“当前视觉输入”与“事件抽帧＋机器人状态＋后续视角”在同一人工验收集上的效果和调用成本。

### 3. 有可靠标注后，训练可控的审核模型

如公司提供所选 MiniMax/OG 版本的多模态微调入口，可以评估使用；否则选择能获得权重并部署的国产视觉模型作为专用审核器，例如 Qwen-VL 或 InternVL 系列的合适版本。

建议首先做监督微调，训练样本组织为：

> 输入：任务说明＋本次阶段目标＋连续多视角画面＋可用机器人状态。
> 输出：阶段/时间边界，以及该目标的完成、未完成或证据不足和证据位置。

阶段识别与目标完成判断分别评估，必要时使用不同模型或预测头。阶段名称和目标要作为条件输入，避免重新退化成固定五类的分类器。若先训练轻量的动作边界检测器，它只负责提出变化时刻，不能替代任务语义和目标判断。

可以尝试 LoRA，即训练少量附加参数，而不是更新所有权重。模型大小、帧数、分辨率、batch size 和是否冻结视觉编码器应经过显存与学习曲线测试后确定。不能直接照抄论文参数并声称适合本机。

优先补充“动作相似、结果不同”的对照样本：拿到了与空抓、放进筐与放在筐后、成功后维持与随后滑落。可借鉴 AHA 从仿真生成可控失败，但仿真真值、图像可观测性和真机域差异必须分别处理；最终验收使用独立真机数据。

MiniMax 可以帮助整理预标注，人工确认后再入训练集。不要把同一个模型的原始预测直接作为训练真值，再用它给自己的新模型打分。当前没有充分证据表明应先投入强化学习或偏好优化；监督标签与验收集可靠后再判断是否需要。

### 4. 长期减少逐段调用大模型

可借鉴 RAFAIL 关注“手—物体”“物体—目标区域”等关系，离线获得监督，训练专用的关系或目标检查器。范本理解保留给 VLM，批量审核尽量交给便宜、可校准的检查器。

RAFAIL 的原方法使用点云、对象分割/跟踪及学习到的关系表示；其中进度与重要性估计还与其策略训练结构有关。我们目前不能把单目 RGB 及未标定的数据当成已经具备这些条件。若用于现有离线遥操作审核，需要独立的适配和验证，不能宣称直接复现。

## 评价是否变准

- **失败被判通过的比例**：优先监控关键失败是否被漏掉，同时报告人工确认成功样本中的误报率。
- **自动通过结论的可靠性**：模型判完成的片段中，人工确认完成的比例。
- **分段质量**：边界时间误差、漏掉/多切的片段数量、重复尝试漏检，以及段级匹配指标。
- **证据不足比例**：与错误率一起报告，避免通过把全部样本标成不确定来得到看似低误判率。
- **运行代价**：每条记录的真实请求数、token 用量、耗时和缓存复用情况。功能测试通过不等于模型识别准确。

达到什么错误率才能进入自动筛选，应根据上级能接受的漏检风险确定。模型版本、提示词、数据版本及测试集必须固定并留痕。

## 已核对的论文

1. **ProTracer: Proprioception-Guided Failure Diagnosis in Robot Manipulation**（2026-09，预印本）。[摘要](https://arxiv.org/abs/2609.21369) · [正文](https://arxiv.org/html/2609.21369v1)。无需新增模型训练，利用夹爪及末端动态寻找关键变化，再用规则生成机器人状态摘要供 VLM 联合判断；还研究失败起点定位。本文最值得优先借鉴。其信号定义、夹爪形式与候选帧预算不应直接照搬到 G1 多指手和移动底座。

2. **RoboProcessBench: Benchmarking Process-Aware Understanding in Vision-Language Robotic Manipulation**（2026-06，本文核对 2026-08 的 v3，预印本）。[摘要](https://arxiv.org/abs/2606.13040) · [正文](https://arxiv.org/html/2606.13040v3)。将机器人过程理解拆成阶段、接触、运动、局部进度、时序、结果及转换等 12 类诊断问题。ProcessData 约 5.8 万问答、260 个操作任务，分为 SFT 与 Eval，按 episode/recording 隔离。论文对 Qwen2.5-VL-7B、InternVL-3-8B 做 LoRA 微调，说明可以用针对性的过程监督改善这些能力。12 类诊断问题不是固定 12 个动作阶段。其评估是分解后的问答测试，不等于我们的完整审核流程已验证。论文使用 4 张 H200 训练、1 张 H200 评估，这是其复现设置，不是对我们硬件需求的估计。

3. **AHA: A Vision-Language-Model for Detecting and Reasoning Over Failures in Robotic Manipulation**（2024-10）。[摘要](https://arxiv.org/abs/2410.00371) · [正文](https://arxiv.org/html/2410.00371v1) · [项目](https://aha-vlm.github.io/)。FailGen 通过对成功仿真示范施加程序化扰动构造失败数据，约 4.9 万图像问答、79 个任务，用于训练失败检测与解释模型。适合借鉴失败样本构建方法，不是给当前公司推理 API 直接增加训练能力，也不能把文中跨域效果视为我们真机数据上的保证。

4. **RAFAIL: Relationship-Aware Failure Detection for Robotic Manipulation**（2026-09，预印本）。[摘要](https://arxiv.org/abs/2609.18324) · [正文](https://arxiv.org/html/2609.18324v1)。离线使用 VLM 提供关系重要性和进度监督，训练基于点云的关系表示及异常检测，部署时避免持续 VLM 推理。值得借鉴“关注任务关系＋离线监督降低运行成本”，但其数据与策略结构前提需要另外满足。

5. **Vision-Language Models as Success Detectors**（2023-03）。[论文](https://arxiv.org/abs/2303.07280)。将任务成功检测组织为带任务描述的视觉问答，并利用人工奖励标注训练；是“目标条件作为输入、成功判定作为监督”的基础参考，年份较早，不列作最新进展。

近期预印本的方法和结果提供研究方向，不替代我们自己的真机验收。建议先实施第 1、2 步，确认主要剩余错误，再启动第 3 步微调。
